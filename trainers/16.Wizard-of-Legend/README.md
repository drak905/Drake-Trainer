# Wizard of Legend — In-Game Trainer & Debug Menu Unlock

Enables the developer debug menu and cheat hotkeys built directly into *Wizard of Legend* (Unity Mono).

## Features & Controls

| Hotkey | Feature / Effect |
| :--- | :--- |
| **Backspace** | **Toggle Debug Menu UI** (ReloadScene, SkipStage, GodMode, MaxDiff, NoClip, WrathOfTheDeveloper, UnlockEverything, DevHub, GotoSpellStore, etc.) |
| **1** | Toggle Max Difficulty |
| **2** | **Toggle God Mode (Invincibility)** |
| **3** | Cycle Slow-Motion Speeds |
| **4** | Toggle Fullscreen Minimap |
| **-** / **=** | Camera Zoom Out / Zoom In |
| *(In Menu)* | **+9999 Gold & +999 Chaos Gems / Platinum** |
| *(In Menu)* | **Wrath of the Developer** (Instantly kills all enemies on screen) |
| *(In Menu)* | **Unlock Everything** (All spells, arcana, relics, robes) |

## Installation

1. Close the game.
2. Double-click Install.bat (or run powershell -ExecutionPolicy Bypass -File .\install.ps1).
3. Launch *Wizard of Legend*. Press **Backspace** or **2** to start cheating!

## Uninstallation

Double-click Uninstall.bat. Your original vanilla Assembly-CSharp.dll is automatically restored.
